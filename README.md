# UBCx Software Development MicroMasters

Repository for exercises, projects, notes, and experiments related to the  
**UBCx MicroMasters Program in Software Development**.

## About

This repository contains learning materials and practical implementations created while studying software development concepts including:

- Programming fundamentals
- Data structures and algorithms
- Object-oriented programming
- Functional programming
- Software architecture
- Testing and debugging
- Version control with Git and GitHub
- Java and Racket programming
- Problem solving and computational thinking

The goal of this repository is to document progress, practice coding skills, and maintain a structured portfolio of coursework and personal implementations.
